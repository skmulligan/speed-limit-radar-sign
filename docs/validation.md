## Software evidence

`python firmware/legacy/tools/run_host_tests.py` runs 28 scenarios across ten host builds.
Tests include captured report parsing plus synthetic malformed input, freshness,
warning transitions, startup/stop handling and rollover. Curated fixture notes specify
which data were captured and which were synthetic. MCU builds verify compilation only.

## Firmware reorganization software checks — 2026-10-29

Verified from both the development and independent public repository roots:

- Legacy: all 28 host scenarios across 10 configurations and all 13 PlatformIO
  environments pass. All 32 SHA256SUMS entries match pre-logging revision 23136da.
- Current: all 50 host scenarios across 15 configurations and all 14 PlatformIO
  environments pass. Runtime sources and pinned configuration remain unchanged.
  The journal host test now uses the system temporary directory instead of a
  macOS-only path; this is a test-harness adaptation, not a firmware change.
- iOS: eight Swift package tests pass and the unsigned simulator build succeeds
  in each checkout. Regenerated C++ records match the existing synthetic Swift
  fixture byte for byte. No real detections are generated by these checks.
- Edition-local includes, ignored generated/secret/user paths, local documentation
  links and serial-tool help entry points pass review. The public package has no
  private baseline helper or bench journal and requires no private Git history.

Verification used macOS, Conda cryoem, PlatformIO Core 6.1.19 and Xcode 27.1.
Other operating systems were not exercised. The current host suite uses POSIX
`mkdtemp`; native Windows needs a POSIX host environment for that test.
No firmware upload, filesystem initialization, app installation, publication,
or new physical validation was performed for this reorganization.
